# 点子篮子 M2 手动验收清单（spec §9 系统集成，不进自动化）

环境：`npm run dev:app`（真机 WebView2）。前置：设置 → 快速捕获 → 开启。

- [ ] 开启开关：托盘出现应用图标；任何应用聚焦时按 Ctrl+Alt+I 唤起捕获小窗（首次为创建，之后为显示）
- [ ] 小窗交互：Enter 入篮后小窗隐藏；Shift+Enter 换行；Esc 隐藏；点击小窗外失焦隐藏
- [ ] 草稿保留：输入未提交 → 失焦隐藏 → 再唤起：草稿仍在（组件未卸载）
- [ ] 中文输入法：合成期 Enter 确认候选不误提交（M1 行为在小窗同样成立）
- [ ] 未设工作区（清空 cfg 的 workspaceDir 后唤起）：窗内提示 +「打开主窗口」按钮可拉起主窗
- [ ] 关窗驻留：主窗 X / Alt+F4 → 应用驻留（托盘在、快捷键仍可用）；托盘「显示主窗口」恢复
- [ ] 关窗时当前图有未保存改动：仍弹三态框，选择后隐藏
- [ ] single-instance：驻留状态下再次启动 exe → 已隐藏的主窗被唤起（Task 4 补的 show()）
- [ ] 托盘「记点子」= Ctrl+Alt+I 同款小窗
- [ ] 托盘「退出」：干净 → 进程结束（任务管理器无残留，含隐藏的捕获窗）；脏 → 仍走三态框
- [ ] 跨窗同步：主窗开着篮子图（干净）→ 小窗记一条 → 主窗静默出现新点子；篮子图有改动 → toast「篮子已在后台更新」
- [ ] 主窗几何记忆：启用前后主窗位置/大小/最大化记忆不受影响（window-state 按 label 分键，R2）
- [ ] 快捷键被占用（可选）：用其他程序占住 Ctrl+Alt+I 再开启 → toast + 设置面板内联错误，功能不静默降级
- [ ] 关闭开关：托盘图标消失、快捷键失效（其他程序可注册）、关窗恢复直接退出
- [ ] 持久化：小窗首条捕获后 cfg.json 出现 quickCapture.enabled 与 basketPath；重启后开关仍开
