# M2 手工验收清单（npm run tauri dev 逐项勾选）

- [ ] 首次启动：选择工作区后进入文件库，列表为空有中文引导
- [ ] 新建：输入中文名创建成功；非法名（a/b、空）出现中文错误提示
- [ ] 编辑：中文输入法录入 Tab/Enter/Delete、双击编辑、拖拽节点、折叠/展开、Ctrl+滚轮缩放画布（注意：默认滚轮是平移）、画布平移
- [ ] 保存：Ctrl+S 后工作区出现 .md 与 .zen.json；.md 内容可直接粘贴给 AI
- [ ] 自动保存：编辑后静置 5 秒，直接关闭应用，重开内容未丢
- [ ] 重开：折叠状态恢复
- [ ] 外部编辑：用记事本改 .md 增加一个二级标题，返回文件库重开导图，新节点出现
- [ ] 删除：确认后文件进入回收站
- [ ] 工作区无 .tmp 残留文件（保存/取消过程中）
- [ ] Windows 下重命名覆盖已存在文件正常（原子写 rename 路径）
- [ ] Windows 高分屏（150%/200% 缩放）显示正常
- [ ] 500+ 节点大图（手工快速 Tab 扩展）无肉眼卡顿
- [ ] 真机验证：错误面板"以纯文本打开修复"按钮能调起系统默认编辑器

## M3 验收（v0.3.0）

- [ ] 复制：无选中 Ctrl+Shift+C = 整图；选中节点后 = 该分支（H1 重计）；粘贴给任意编辑器核对
- [ ] 多行粘贴：编辑节点时粘贴 3 行文本 → 首行入当前节点、后两行成子节点
- [ ] 关闭守卫：编辑后直接点窗口 × → 三态各试一遍（保存关闭/放弃/取消）
- [ ] 保存失败：占用 .md 文件（如用 Word 打开锁定）后 Ctrl+S → 横幅报错、返回不离开
- [ ] 忽略块：用记事本往 .md 里加一段文字 → 打开有横幅 → 保存时确认丢弃
- [ ] 导入：选一个含段落的外部 .md → 预览提示 → 确认入库 → 原文件未动
- [ ] 布局：三布局切换即时重排，重开恢复；切换不出现 ● 脏标记
