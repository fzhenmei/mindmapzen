# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest release | ✅ |
| anything older | ❌ — please upgrade first |

mind-map-zen is a local-first desktop app: your notes and maps stay on your own machine.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Use GitHub's private vulnerability reporting instead: **Security** tab → **Report a vulnerability**. Details stay private until a fix ships.

- Include the app version and, if possible, steps to reproduce.
- Solo maintainer, best effort — expect an acknowledgment within a few days.
